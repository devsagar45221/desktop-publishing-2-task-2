# desktop-publishing-2-task-2
Open Adobe Photoshop and select an ordinary photograph using File → Open.
Save a working copy of the photograph in PSD format.
Select the Crop Tool (C) to crop unnecessary areas and straighten the image.
Adjust the image brightness and contrast using Image → Adjustments → Brightness/Contrast.
Correct the colors using Image → Adjustments → Color Balance.
Adjust the color intensity using Image → Adjustments → Hue/Saturation.
Use the Spot Healing Brush Tool (J) to remove small unwanted spots and blemishes.
Use the Healing Brush Tool (J) to repair imperfections by sampling a clean area of the photograph.
Use the Clone Stamp Tool (S) to remove unwanted objects by copying pixels from a suitable nearby area.
Remove at least three unwanted spots or objects from the photograph using the appropriate retouching tools.
Compare the edited image with the original photograph and ensure that the retouching looks natural.
Create a Before and After comparison by placing the original and edited images side by side in a new document.
